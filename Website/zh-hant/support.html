找不到授權碼

  • 它在你的客戶中心。請用付款時的電子郵件登入。
  • 如果你是在這個瀏覽器購買的，首頁上也看得到。

換新 Mac

  • 一組授權碼可同時用於 3 台 Mac。
  • 若要空出名額，請在 Outbound 的設定中按一下「停用」，或使用客戶中心。
  • 在新的 Mac 上，從選單列選擇「解鎖 Outbound」，然後貼上你的授權碼。

畫面不動了

  • 桌面被遮住、螢幕進入睡眠或低耗電模式開啟時，它就會暫停。
  • 離開 5 分鐘後它會靜止下來，移動滑鼠就會醒來。
  • 是你自己暫停的嗎？在選單列選擇「繼續」。

移除

  • 在選單列選擇「結束 Outbound」，就會換回你原本的桌布。
  • 接著把 Outbound 從「應用程式」檔案夾拖到垃圾桶。

收據

  • 都在你的客戶中心。

發現錯誤

  • 寄電子郵件給我們，或在 GitHub 上提出 issue。請說明你使用的 Mac 和 macOS 版本。
